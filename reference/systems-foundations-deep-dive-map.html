Networking and Operating Systems Foundations

Networking from application request, addressing, routing, transport, congestion, DNS, TLS, and HTTP through operating-system syscalls, processes, scheduling, synchronization, memory, storage, containers, and observability. This map links all 12 lessons in their recommended sequence.

  1. 01Request to wire, sockets, encapsulation, frames, packets, segments, and application messages
  2. 02IPv4, IPv6, CIDR, subnet masks, MAC addresses, ARP, and neighbor discovery
  3. 03Routing tables, longest-prefix match, default gateways, ICMP, traceroute, and NAT
  4. 04UDP, TCP, ports, sockets, handshakes, sequence numbers, acknowledgements, MTU, and MSS
  5. 05TCP flow control, congestion control, slow start, AIMD, retransmission, backpressure, and overload
  6. 06DNS resolution, TLS handshakes, certificates, HTTP semantics, HTTP versions, and connection reuse
  7. 07System calls, user mode, kernel mode, file descriptors, process creation, exec, signals, and exit
  8. 08Processes, threads, process control blocks, context switches, CPU scheduling, and IPC
  9. 09Race conditions, locks, semaphores, condition variables, atomics, deadlocks, and lock ordering
  10. 10Address spaces, segmentation, paging, page tables, the MMU, virtual memory, demand paging, and replacement
  11. 11I/O, disks, SSDs, files, directories, VFS, buffering, caching, journaling, and durability
  12. 12Namespaces, cgroups, containers, virtualization, resource limits, observability, and systems debugging capstone
