Answer from a recording without inventing what happened

Start with the example, then work through the pipeline. In the first session, practise timestamps and evidence. In the second, design and evaluate a small recording assistant. Media decoding and model calls are optional future integration work; the supplied offline example uses invented transcript and frame records.

A recording is a timeline

At 12–15 seconds, a speaker says “Do not restart the pump.” At 14 seconds, the screen shows “Power isolated.” Your assistant must preserve the word “not,” the time, and the difference between a spoken instruction and a visible status. A fluent summary that says “Restart the pump” is unsafe even if most words were transcribed correctly.

Think of a recording as a picture book with a clock on every page. A transcript records the words. A frame records one picture. Neither alone tells you everything between the pages.

Authorized upload → bounded decode → audio segments + video frames
       → timestamped transcript / visual evidence → retrieve → cited answer
       → review uncertainty and consequential actions

Turn audio into useful evidence

A sample rate is the number of audio measurements per second. A channel is a separate audio signal. A codec describes how media is encoded. Match the actual encoding and rate to the transcription service; changing a declared rate does not resample audio. Preserve the original privately and version each transformation.

Automatic speech recognition converts speech to text. Voice activity detection finds likely speech intervals; it does not transcribe them. Diarization groups speech by speaker. A label such as spk_0 is not a verified person's identity. Channel separation may help when participants were recorded separately, but one channel need not equal one person. See Transcribe input formats and speaker labels and timestamps.

Split long recordings into bounded segments. Overlap can preserve words at boundaries but creates duplicates that need alignment. Store segment-relative and original-media times. If a segment begins at 120 seconds and a word begins at 2.4 seconds within it, its source time is 122.4 seconds. Preserve gaps rather than pretending speech continued.

Streaming transcripts may contain provisional words that later change. Keep revision IDs and publish stable final spans for durable citations. Handle reconnects and duplicate segments by source/version/time identity. Bound retries, queue age, concurrent jobs and decoded duration; compressed file size alone does not bound processing work.

Choose video frames deliberately

Uniform sampling takes a frame at a fixed interval. Scene-change sampling focuses on visual changes. Query-guided sampling revisits relevant intervals at higher density. Uniform sampling is simple, but a one-second warning can fall between five-second samples. Scene changes can miss small but important changes on a static screen.

A video model processes selected visual inputs under model-specific limits. More frames increase resource use and may improve temporal coverage, but do not guarantee understanding. Follow the selected model's processor rather than passing arbitrary images in an assumed format. See the video-text task guide.

Use presentation timestamps, not frame number divided by an assumed frame rate, especially for variable-frame-rate media. Store the clip offset, frame timestamp and sampling policy. If audio was trimmed or resampled, maintain its mapping to the original timeline. Test a known sound/visual marker for drift.

OCR reads visible text. Image descriptions summarize visual content. Keep both linked to frames, and do not treat descriptions as ground truth. Motion requires multiple observations: a single frame cannot prove the pump remained stopped throughout an interval. Return “not established by the sampled frames” when evidence is insufficient.

Build a recording assistant

  1. Choose one consented, non-sensitive recording and three questions: spoken instruction, visible status, and an intentionally unanswerable question. Do not upload customer calls by default.
  2. Define records: source_id, version, start_ms, end_ms, speaker_label, text, frame_timestamp, access scope and processing-model version. Store explicit milliseconds; do not mix seconds and milliseconds.
  3. Run the offline timeline demo in the practice package. Predict which frame overlaps the spoken instruction before checking its output.
  4. In an approved environment, transcribe bounded audio segments and sample frames. Save raw provider responses privately, then normalize them to the record contract. Never infer a human name from a speaker number.
  5. Index transcript spans and frame descriptions. Retrieve only authorized evidence, then join nearby modalities by time. Temporal overlap is an association, not proof that text and picture agree.
  6. Generate an answer with source/version/time references. A playback link must reauthorize access; a public signed URL with a long lifetime is not an access policy.
  7. Review disagreements, missing speech, overlapping speakers and unsupported claims. Keep actions such as sending minutes or creating work orders behind explicit approval.

Expected demo: the 14-second frame overlaps the 12–15-second transcript; the 20-second frame does not. This verifies interval selection only. It does not verify transcription, visual interpretation or semantic support.

Evaluate the errors that matter

Word error rate is (substitutions + deletions + insertions) / reference words. It can exceed 100%. Define normalization before scoring. With reference “do not restart” and output “do restart,” one deletion gives 1/3 WER. Yet that one word reverses the instruction. Track critical-term accuracy and instruction reversals separately.

For speaker quality, measure attribution errors and, with an appropriate diarization evaluator, missed speech, false alarms and speaker confusion. Document overlap handling and boundary tolerance. A correct transcript can still attribute an instruction to the wrong person.

Label relevant intervals and frames. Measure event recall, timestamp accuracy, citation support and abstention on missing evidence. Split evaluation by recording or meeting, not random adjacent chunks from the same session. Include accents, noise, silence, music, cross-talk, tiny screen text and short-lived warnings. Compare transcript-only with transcript plus frames.

Trace decode, transcription, sampling, retrieval and generation separately. Track duration processed, frames, tokens, failures and total cost per recording. Measure queue delay and end-to-end p95. Redact logs, apply retention to originals and derivatives, and test deletion through indexes and caches. Treat speech, screen text and subtitles as untrusted content that can contain prompt injection.

Check your reasoning

Can spk_0 approve a payment?

No. Diarization is not authentication. Verify an authorized person's identity through the application and require approval of the exact action.

Why can low WER still be unsafe?

An error in a negation, quantity or identifier can dominate business risk. Report those slices and route uncertain consequential cases to review.

MCQ: A warning appears between sampled frames. Is the correct conclusion “warning absent” or “warning unobserved”?

Warning unobserved. Missing sampled evidence does not prove absence. Request denser evidence or abstain.
