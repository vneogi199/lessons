Neural-network calculation card

  • Neuron: multiply each input by its weight, sum, add bias, apply activation.
  • ReLU(z) = max(0, z). ReLU has no learned parameters.
  • Dense layer with m inputs and n outputs: mn weights, plus n biases if enabled.
  • 2 → 2 → 1 dense network with biases: 6 + 3 = 9 parameters.
  • Basic transformer FFN d → f → d: 2df weights, plus f + d biases if enabled. Gated variants differ.
  • Count shared parameter storage once. Frozen parameters remain part of total parameters.
  • Batch size and sequence length change computation and intermediate storage, not the number of shared layer parameters.

Do not mix up these terms

Weights and biases are model parameters. Learning rate and hidden width are hyperparameters. Activations, attention scores, and cached keys and values depend on the input. Gradients guide updates; they are not extra model parameters.

A forward pass computes the output. Backpropagation computes derivatives of loss. The optimizer updates trainable parameters. Ordinary inference does not update them.

Check yourself: a 3 → 4 → 2 dense network with biases has 16 + 10 = 26 parameters. Explain why evaluating it on ten examples does not make that 260.
