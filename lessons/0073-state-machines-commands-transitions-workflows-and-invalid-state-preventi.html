01

State machines

A state machine defines possible states and allowed transitions. Valid state shapes alone do not enforce valid transitions.

02

commands

A command expresses intent to perform an operation. The receiver may accept or reject it according to its current state and policy.

03

transitions

Transitions move a system between states under a condition or event. State the guard, side effects, and failure behavior.

04

workflows

A workflow coordinates dependent steps and their recovery. Durable workflows must distinguish retries from new attempts.

05

invalid-state prevention

Prevent invalid states by making required relationships explicit and rejecting transitions or inputs that violate them.

from enum import Enum, auto

class State(Enum):
    NEW = auto(); PAID = auto(); CANCELLED = auto(); SHIPPED = auto()

TRANSITIONS = {
    (State.NEW, "pay"): State.PAID,
    (State.NEW, "cancel"): State.CANCELLED,
    (State.PAID, "ship"): State.SHIPPED,
}

def transition(state: State, command: str) -> State:
    try: return TRANSITIONS[(state, command)]
    except KeyError: raise ValueError(f"invalid: {state.name} -> {command}") from None

assert transition(transition(State.NEW, "pay"), "ship") is State.SHIPPED
try: transition(State.CANCELLED, "ship")
except ValueError: pass
else: raise AssertionError("forbidden transition accepted")
