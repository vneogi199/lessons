Objects, identity, type, value, references, mutability, and aliasing

ELI5 example

Put two name stickers on one toy box. Adding a toy through either label changes the same box. In Python, two names can refer to one list in the same way.

Assigning one name to a new list moves that name to a different object. It does not move the other name. This explains why changing a shared list and assigning a new list have different effects.

If one name is assigned a new list, does the other name follow?

No. The other name still refers to the original list.

Understand that names bind to objects, assignment copies references, mutation changes an object, and identity, type, and value are distinct properties.

Python names are sticky notes attached to objects: assignment moves a note, mutation changes the object, and protocols define which tools know how to use it.

01

Objects

Every Python value is represented by an object or a relationship between objects. Each object has an identity, a type, and a value.

02

identity

Identity answers whether two references point to the same object. Use is for singleton identity such as None, and equality for value comparison.

03

type

An object's type determines supported behavior and operations. An annotation does not change the runtime object's type.

04

value

A value is the state represented by an object; names bind to objects rather than storing independently typed slots.

05

references

A Python variable stores a reference binding rather than a box that contains a copied value. Assignment rebinds a name, while mutation changes the referenced object.

06

mutability

A mutable object's value can change after creation; an immutable object's direct contents cannot. Immutability does not prevent an immutable container from referencing a mutable child.

07

aliasing

Aliasing occurs when multiple names or containers reference the same object. A mutation through one path is then visible through every other alias.

original = {"members": [{"name": "Ada"}]}
alias = original
shallow = copy(original)
deep = deepcopy(original)

original["members"][0]["name"] = "Grace"

assert alias is original
assert shallow is not original
assert shallow["members"] is original["members"]
assert deep["members"] is not original["members"]
assert original == shallow
