08 · Common mistakes

Memorizing the label

A definition is not enough. Trace a render and commit cycle from input to output.

Testing only success

The happy path can hide a weak design. Try this failure: Change one input or key and predict which component state is preserved.

Changing too much

Change one condition at a time. Otherwise, you will not know what caused the result.

Guessing

Check the system instead: React DevTools, render count, DOM mutations, focus, and displayed state.
