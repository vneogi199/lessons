04 · Detailed term guide

How they connect: Study object reachability, CPython reference counts, generational cycle detection, weak-reference callbacks, finalizers, resurrection, and implementation differences.

01

Memory management

What it means: Memory management decides when storage for Python objects can be reclaimed. The language specifies reachability behavior broadly; concrete collectors differ by implementation.

02

reference counting

What it means: CPython reference counting tracks strong references and often finalizes unreachable non-cyclic objects promptly. It cannot by itself reclaim cycles.

03

cyclic GC

What it means: The cyclic garbage collector finds unreachable reference cycles that reference counts alone cannot release. It supplements, rather than replaces, CPython reference counting.

04

weak references

What it means: A Python variable stores a reference binding rather than a box that contains a copied value. Assignment rebinds a name, while mutation changes the referenced object.

05

finalization

What it means: finalization is one part of Python's object, execution, or runtime model. Ask which objects and names participate, which protocol or boundary performs the work, what state or resource changes, and which evidence makes the behavior observable.

import gc
import weakref

class Node:
    def __init__(self, name: str):
        self.name = name
        self.other = None

left, right = Node("left"), Node("right")
left.other, right.other = right, left
observed = weakref.ref(left)

del left, right
collected = gc.collect()
assert observed() is None
print({"cyclic_objects_collected": collected, "thresholds": gc.get_threshold()})

08 · Common mistakes

Memorizing the label

A definition is not enough. Trace an object's lifetime from input to output.

Testing only success

The happy path can hide a weak design. Try this failure: Create an alias or cycle, delete roots, and predict which objects remain reachable.

Changing too much

Change one condition at a time. Otherwise, you will not know what caused the result.

Guessing

Check the system instead: Object IDs, weak references, GC statistics, allocation trace, and cleanup events.
