01

Pagination offset

Pagination returns a bounded part of an ordered collection plus enough continuation state to request the next part.

02

keyset

Keyset pagination continues after the last ordered values already seen, avoiding the growing scan and shifting offsets of offset pagination.

03

cursor

A cursor is an opaque continuation token that binds position to ordering, filters, version, authorization scope, and sometimes a snapshot or expiry.

04

snapshots

A snapshot captures a view of state at a defined boundary. State what consistency it guarantees and whether concurrent changes are included.

05

stable ordering

Stable ordering uses deterministic tie-breakers so pagination and repeated reads have a defined sequence.

Common mistakes

Memorizing the label

A definition is not enough. Trace a distributed request or message from input to output.

Testing only success

The happy path can hide a weak design. Try this failure: Repeat or condition the same request through one intermediary and predict every observable difference.

Changing too much

Change one condition at a time. Otherwise, you will not know what caused the result.
