04 · Detailed term guide

How they connect: Separate base-model learning from post-training alignment and product prompting.

01

Pretraining

What it means: Pretraining learns broad statistical patterns from a large dataset before task-specific adaptation.

02

next-token prediction

What it means: Next-token prediction trains a model to estimate the next token from earlier tokens.

03

fine-tuning

What it means: Fine-tuning continues model training on a smaller dataset for a task, domain, or behavior.

04

instruction tuning

What it means: Instruction tuning trains a model on instructions and desired responses so it follows user tasks more reliably.

05

preference optimization

What it means: Preference optimization adjusts model behavior using comparisons or scores that represent preferred responses.

function softmax(logits) {
  const max = Math.max(...logits);
  const weights = logits.map(x => Math.exp(x - max));
  const total = weights.reduce((a, b) => a + b, 0);
  return weights.map(x => x / total);
}

08 · Common mistakes

Memorizing the label

A definition is not enough. Trace a token sequence from input to output.

Testing only success

The happy path can hide a weak design. Try this failure: Change tokenization or decoding settings while holding the prompt fixed.

Changing too much

Change one condition at a time. Otherwise, you will not know what caused the result.

Guessing

Check the system instead: Token IDs, attention or logits where available, selected token, latency, and output variance.
