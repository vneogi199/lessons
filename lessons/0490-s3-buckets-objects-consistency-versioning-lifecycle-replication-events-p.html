S3 buckets

An S3 bucket holds objects under bucket-specific naming, location, access and lifecycle rules. Bucket type matters; the versioned-object exercise uses general-purpose bucket semantics.

objects

An S3 object contains bytes plus metadata addressed by a bucket and key, with a version ID when supported and enabled. Key prefixes organize names; they are not filesystem directories.

consistency

Consistency specifies which combinations and orderings of observations are permitted. Name the model instead of treating consistency as a boolean.

versioning

S3 versioning retains distinct object versions and uses delete markers for ordinary deletion. Deleting an explicit version removes that version; lifecycle policies can still expire retained history.

lifecycle

A lifecycle is the sequence from creation through use to termination or release. Each transition needs a responsible component and defined failure behavior.

replication

Replication copies data to other eligible locations under a configured service contract. Lag, conflict, deletion and failover semantics vary; a replica is not automatically an independent backup.

events

Events report something that occurred. Specify identity, ordering scope, delivery behavior, and payload evolution.

policies

AWS permission policies contain effect, action, resource and optional condition statements. Whether a policy grants access or only limits it depends on its type and attachment.

data protection

Data protection combines access restrictions, encryption, version retention, recoverable backups and verified restore procedures. Each control addresses a different path to loss or exposure.

S3 addresses bytes by bucket and key, with separate version identities when versioning is enabled. An ordinary delete can add a marker while older versions remain. Deleting an explicit version removes that version unless another copy exists. Versioning alone configures neither replication nor lifecycle policy. Strong object consistency also does not make several object updates one atomic operation.
