01

Namespaces

Namespaces separate names or views of resources within a scope. They are not automatically complete security or resource-isolation boundaries.

02

cgroups

Linux control groups account for and limit resources used by groups of processes, such as CPU and memory. Resource controls complement namespace isolation.

03

containers

Containers package and run processes with operating-system isolation and resource controls; they usually share a host kernel.

04

virtualization

Virtualization presents an abstract machine or resource view. Distinguish guest-kernel isolation from process containers sharing a kernel.

05

resource limits

Resource limits bound consumption or admission, such as memory, CPU, payload size, or concurrency. Define rejection and recovery behavior.

06

observability

Observability is the ability to investigate system behavior using its outputs, such as metrics, logs, traces, and profiles. Collect signals that can distinguish competing explanations for a failure.

07

systems debugging capstone

The systems capstone links application symptoms to process, memory, filesystem, and network evidence, validating the actual failure cause.

import os
import platform
import resource

def snapshot() -> dict[str, object]:
    usage = resource.getrusage(resource.RUSAGE_SELF)
    return {
        "pid": os.getpid(),
        "platform": platform.system(),
        "user_cpu_seconds": usage.ru_utime,
        "system_cpu_seconds": usage.ru_stime,
        "open_file_limit": resource.getrlimit(resource.RLIMIT_NOFILE)[0],
    }

evidence = snapshot()
assert evidence["pid"] > 0
assert evidence["open_file_limit"] == resource.RLIM_INFINITY or evidence["open_file_limit"] > 0
