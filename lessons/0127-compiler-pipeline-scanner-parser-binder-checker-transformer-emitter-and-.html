Compiler pipeline, scanner, parser, binder, checker, transformer, emitter, and language service

TypeScript checks information about JavaScript code before the JavaScript program runs.

Senior practice for this track ↗ · The reading estimate excludes the lab and interview rehearsal.

The scanner reads tokens, the parser builds syntax, and the binder connects declarations to symbols. The checker then reasons about types and their relationships. Transformation and emission produce output. These are separate jobs: transforming a single file with transpileModule does not perform a full semantic check or a declaration build. Inspect each output separately before deciding which phase established a claim.

01

Compiler pipeline

The compiler parses files, binds declarations into symbols, checks types and relationships, transforms syntax when necessary, and emits JavaScript or declarations.

02

scanner

The scanner turns source characters into tokens while tracking trivia and positions. Parsing consumes those tokens to construct syntax nodes.

03

parser

The parser creates a syntax tree from tokens. A valid AST does not imply the program's names or types are semantically valid.

04

binder

The binder walks syntax and creates symbols, scopes, and declaration relationships. It establishes named identity before the checker computes most types.

05

checker

The checker computes types at program locations and evaluates relationships such as assignability, inference, narrowing, and overload selection.

06

transformer

A compiler transformer rewrites syntax trees for output, such as lowering newer syntax. Transformation is separate from proving type compatibility.

07

emitter

The emitter prints JavaScript, declaration files, and source maps from the transformed program. Most type information is erased before runtime.

08

language service

The language service incrementally answers editor queries such as diagnostics, Quick Info, navigation, refactoring, and completion through a host-managed project view.

import ts from "typescript";

const source = "export const answer: number = 42";
const file = ts.createSourceFile("lesson.ts", source, ts.ScriptTarget.Latest, true);

function visit(node: ts.Node, depth = 0): void {
  console.log("  ".repeat(depth) + ts.SyntaxKind[node.kind]);
  node.forEachChild(child => visit(child, depth + 1));
}
visit(file);

const emitted = ts.transpileModule(source, {
  compilerOptions: { target: ts.ScriptTarget.ES2020, declaration: true },
  reportDiagnostics: true
});
console.log(emitted.outputText, emitted.diagnostics);
