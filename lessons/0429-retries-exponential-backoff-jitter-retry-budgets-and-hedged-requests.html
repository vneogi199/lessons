Retries

A retry makes another attempt after failure or uncertainty. Bound attempts and elapsed time, and repeat side effects only when their contract supports safe retries.

exponential backoff

Exponential backoff increases the delay between attempts, usually up to a limit. It reduces repeated pressure but still needs a retry budget and safe operation semantics.

jitter

Jitter adds randomness to retry timing so many clients do not retry at the same instant. It spreads load without making an unsafe operation idempotent.

retry budgets

A retry budget limits extra attempts relative to healthy traffic so retries cannot turn a small failure into uncontrolled load.

hedged requests

A hedged request starts a duplicate after a delay to reduce tail latency, at the cost of added work and duplicate side-effect risk.

Retries spend additional capacity to recover from selected failures. Bound total attempts, use backoff with jitter and stop when the deadline or retry budget is exhausted. Keep the same logical operation identity when an effect may already have happened. The fixture's always-allowing budget is not fleet protection. Hedged calls create concurrent work and need their own cost, cancellation and duplicate-effect policy.

// Node.js module: retry only operations safe to repeat under the SAME identity.
import assert from "node:assert/strict";
import { setTimeout as sleep } from "node:timers/promises";

async function retry(operation, { signal, isTransient, budget, maxAttempts = 3, baseMs = 50 }) {
  if (!Number.isSafeInteger(maxAttempts) || maxAttempts < 1 || !Number.isFinite(baseMs) || baseMs < 0) {
    throw new RangeError("invalid retry limits");
  }
  for (let attempt = 1; ; attempt += 1) {
    signal.throwIfAborted(); // Includes cancellation before the first attempt.
    try { return await operation({ signal, attempt }); }
    catch (error) {
      signal.throwIfAborted();
      if (attempt >= maxAttempts || !isTransient(error) || !budget.take()) throw error;
      const cap = baseMs === 0 ? 0 : Math.min(1000, baseMs * 2 ** Math.min(attempt - 1, 30));
      await sleep(Math.random() * cap, undefined, { signal }); // full jitter
    }
  }
}

const options = {
  signal: new AbortController().signal, baseMs: 0,
  isTransient: error => error.message === "temporary", budget: { take: () => true }
};
let calls = 0;
assert.equal(await retry(async () => {
  if (++calls < 3) throw new Error("temporary");
  return "ok";
}, options), "ok");
assert.equal(calls, 3);
for (const override of [{ maxAttempts: 1 }, { budget: { take: () => false } }, { isTransient: () => false }]) {
  calls = 0;
  await assert.rejects(retry(async () => { calls++; throw new Error("temporary"); }, { ...options, ...override }), /temporary/);
  assert.equal(calls, 1);
}
calls = 0;
await assert.rejects(retry(async () => { calls++; }, {
  ...options, signal: AbortSignal.abort(new Error("cancelled"))
}), /cancelled/);
assert.equal(calls, 0);
await assert.rejects(retry(async () => "unused", { ...options, maxAttempts: 0 }), RangeError);
