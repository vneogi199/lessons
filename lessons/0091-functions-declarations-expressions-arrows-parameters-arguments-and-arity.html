Functions, declarations, expressions, arrows, parameters, arguments, and arity

JavaScript is a programming language. A JavaScript engine reads the program and performs its operations.

A function's form affects more than its syntax. Ordinary functions and arrows handle this, arguments and construction differently. Default parameters apply to undefined, not null, and rest parameters collect remaining arguments. The length property describes part of the parameter list; it does not validate calls or limit how many arguments a caller can pass. 01

Functions

A function is a callable object with code and an associated lexical environment. Its return value, parameters, this behavior, and ability to construct depend on the function form.

02

declarations

Declarations introduce bindings or definitions, such as let, const, function, and class. Their creation and initialization timing differs, which explains hoisting and temporal-dead-zone behavior.

03

expressions

An expression is evaluated to produce a value or an abrupt completion such as an exception. A function expression creates a function value where an expression is allowed.

04

arrows

An arrow function resolves this and arguments lexically and cannot be called with new. Replacing an ordinary method with an arrow can therefore change behavior.

05

parameters

Parameters are the function's input bindings. Defaults apply when the argument is undefined, and a rest parameter collects remaining arguments into an array.

06

arguments

For an ordinary function, arguments is an array-like object describing arguments passed to that call. Arrow functions have no own arguments object and resolve the name lexically.

07

arity

Arity usually describes a function's parameter count. JavaScript's function.length counts parameters before the first default and excludes a rest parameter; it is not a runtime argument limit.

"use strict";
const account = {
  balance: 40,
  read(prefix = "balance") { return prefix + ":" + this.balance; }
};

const detached = account.read;
console.assert(account.read() === "balance:40");
console.assert(detached.call(account, "call") === "call:40");
console.assert(detached.apply(account, ["apply"]) === "apply:40");

const bound = detached.bind(account, "bound");
console.assert(bound() === "bound:40");

function Account(balance) {
  if (!new.target) throw new TypeError("use new");
  this.balance = balance;
}
const instance = new Account(42);
console.assert(Object.getPrototypeOf(instance) === Account.prototype);

const lexicalThis = () => this;
console.assert(lexicalThis.call(account) === undefined);
