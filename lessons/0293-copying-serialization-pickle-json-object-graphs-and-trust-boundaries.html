Copying

A shallow copy creates a new outer object while retaining references to nested objects. A deep copy recursively recreates much of an object graph and needs explicit semantic justification.

serialization

Serialization converts in-memory values into a transport or storage representation. The format loses or transforms some type, identity, and behavior information.

pickle

pickle serializes Python-specific object graphs using executable reconstruction instructions. Loading untrusted pickle data can execute arbitrary code.

JSON

JSON serialization maps supported values to a text interchange format; parsing does not validate application-specific structure.

object graphs

Object graphs describe references connecting objects, explaining reachability, sharing, cycles, and retained memory.

trust boundaries

A trust boundary separates data or authority with different levels of trust. Validate input and enforce permission when crossing it before performing privileged work.

A shallow copy separates outer storage while retaining child references. A deep copy traverses the graph under a copying protocol and can preserve shared relationships and cycles. Serialization has a different contract: JSON cannot preserve every Python type or identity relationship. Pickle can reconstruct more Python-specific objects, but loading it can execute code. Treat format versions and trust as part of the input boundary, not as details to fix after decoding.

ELI5 example

Copying a list makes another Python object. Serializing it writes a representation that can be stored or sent. Those operations solve different problems.

JSON does not preserve every Python type or shared-reference relationship. Pickle supports more Python-specific behavior, but loading an untrusted pickle can execute code. Use a format and validation policy appropriate to the boundary.

Should you unpickle an unknown file just to inspect its data?

No. Loading untrusted pickle data is unsafe.

from copy import copy, deepcopy
import json
import pickle

graph = {"members": [{"id": 1}]}
shallow = copy(graph)
deep = deepcopy(graph)
assert shallow["members"] is graph["members"]
assert deep["members"] is not graph["members"]

def encode_project(project: dict) -> bytes:
    envelope = {"schema_version": 1, "project": project}
    return json.dumps(envelope, separators=(",", ":")).encode("utf-8")

def decode_project(payload: bytes) -> dict:
    if not isinstance(payload, bytes) or len(payload) > 65_536:
        raise ValueError("bounded bytes required")
    envelope = json.loads(payload)
    if not isinstance(envelope, dict) or set(envelope) != {"schema_version", "project"}:
        raise ValueError("invalid envelope")
    if type(envelope["schema_version"]) is not int or envelope["schema_version"] != 1:
        raise ValueError("unsupported schema")
    if not isinstance(envelope["project"], dict):
        raise ValueError("project must be an object")
    return envelope["project"]

assert decode_project(encode_project({"name": "demo"})) == {"name": "demo"}
for invalid in ([], {"schema_version": True, "project": {}}, {"schema_version": 1, "project": []}):
    try:
        decode_project(json.dumps(invalid).encode())
    except ValueError:
        pass
    else:
        raise AssertionError("invalid envelope accepted")
