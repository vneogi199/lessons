Hoisting

Hoisting is shorthand for declaration-instantiation effects before statement execution. Different declarations create and initialize their bindings at different times.

var

var declares a function-scoped or script-global binding, initialized to undefined before statement execution. It does not create a block-scoped binding.

let

let creates a reassignable lexical binding scoped to its block. Access before initialization throws ReferenceError, even when using typeof on that binding.

const

const creates a lexical binding that cannot be reassigned after initialization. It does not make an object held by the binding immutable.

temporal dead zone

A lexical binding is in its temporal dead zone from scope entry until initialization. Access during that interval throws ReferenceError.

global bindings

Global bindings are names accessible through the global environment. In browser scripts, top-level var and top-level let do not have identical relationships to properties of the global object.

JavaScript establishes declarations before evaluating the statements in their scope. A var binding starts as undefined. A lexical binding exists before initialization but cannot be read during that interval, called the temporal dead zone. Hoisting is shorthand for these rules, not source code physically moving upward. A const declaration prevents reassignment of its binding; it does not freeze the object that binding refers to.
