01

Amazon Bedrock

Amazon Bedrock provides managed access to foundation models and related AI capabilities. Application identity, data boundaries, evaluation, safety, latency, and cost still belong to the workload.

02

SageMaker

SageMaker provides managed capabilities for building, training and serving machine-learning workloads. Select the specific offering and own data, model quality, access and operating cost.

03

model access

Model access requires eligible account/Region availability, permission and any model-specific terms or prerequisites. A valid SDK call shape does not establish access to every model.

04

inference

Inference executes a trained model on input to produce output. Model version, input context, decoding and service limits shape quality, latency and cost.

05

agents

Model-driven agents select actions through a control loop with tools and state. Restrict authority and bound steps, time and cost while verifying effects outside the model.

06

knowledge bases

Managed knowledge bases connect ingestion and retrieval to generation through configured sources and indexes. Freshness, permission filtering and answer grounding still require application evaluation.

07

guardrails

AI guardrails apply configured checks or restrictions to supported inputs and outputs. They can miss threats and do not replace tool authorization, data isolation or release evaluation.

08

evaluation

AI evaluation measures defined tasks against datasets, rubrics and baselines. Report slices, failures and uncertainty along with latency and cost before accepting a release.

09

AI security

AI security controls untrusted context, data exposure and tool authority across model workflows. Treat generated actions as untrusted proposals until validated and authorized.

import boto3

def text_answer(response):
    # This adapter accepts only a completed, text-only turn; not tool use or truncation.
    if not isinstance(response, dict) or response.get("stopReason") != "end_turn":
        raise ValueError("completed text turn required")
    output = response.get("output")
    message = output.get("message") if isinstance(output, dict) else None
    content = message.get("content") if isinstance(message, dict) else None
    if not isinstance(content, list) or not content or any(
        not isinstance(block, dict) or set(block) != {"text"} or not isinstance(block["text"], str)
        for block in content
    ):
        raise ValueError("text-only content required")
    answer = "".join(block["text"] for block in content)
    if not answer.strip(): raise ValueError("empty answer")
    return answer
