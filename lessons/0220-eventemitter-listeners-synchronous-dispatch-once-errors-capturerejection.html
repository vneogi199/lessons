EventEmitter, listeners, synchronous dispatch, once, errors, captureRejections, and leaks

Node.js runs JavaScript outside a browser. It connects JavaScript to files, networks, processes, and operating-system services.

Senior practice for this track ↗ · The reading estimate excludes the lab and interview rehearsal.

EventEmitter calls listeners synchronously during emit. An async listener can return a Promise, but emit does not await it. Register a one-time listener before the event occurs. CaptureRejections can route rejected listener promises without becoming a catch for every synchronous throw. Listener registrations also retain functions and captured state until removed; a warning threshold diagnoses growth without enforcing a memory limit.

01

EventEmitter

EventEmitter invokes registered listeners synchronously in order when emit is called. Emission itself is ordinary JavaScript, not an event-loop phase.

02

listeners

A listener registration holds a strong function reference until removed. Unbounded or repeated registration can retain request state and produce duplicate work.

03

synchronous dispatch

EventEmitter normally invokes listeners synchronously during emit; an async listener's Promise is not automatically awaited.

04

once

A once listener is removed after its first invocation; Promise-based event waiting needs error and cancellation consideration.

05

errors

Errors report failed operations. Preserve useful causes, distinguish expected failures, and avoid leaking sensitive internal details.

06

captureRejections

captureRejections observes rejected Promises returned by async listeners and routes them toward a rejection handler or error event instead of silently losing them.

07

leaks

A leak retains resources longer than their intended lifetime. Look for growing ownership paths such as listeners, caches, handles, or unfinished work under comparable load.

import { EventEmitter, once } from "node:events";

const lifecycle = new EventEmitter({ captureRejections: true });
lifecycle.on("error", error => console.error({ event: "lifecycle.error", error }));

function onReady(value) { console.log("ready", value); }
lifecycle.on("ready", onReady);
lifecycle.once("closed", () => console.log("closed once"));

lifecycle.emit("ready", { port: 3000 }); // listeners run synchronously, in order
lifecycle.off("ready", onReady);         // remove the same function identity

const closed = once(lifecycle, "closed");
lifecycle.emit("closed");
await closed;
console.assert(lifecycle.listenerCount("ready") === 0);
