01

Generators

A generator object is both iterator and suspended computation. Calling next, throw, or return resumes it until another yield or completion.

02

yield

yield suspends a generator and exposes a value to its consumer. A later next(value) resumes execution and supplies the result of the suspended yield expression.

03

yield star

yield* delegates iteration to another iterable. It forwards traversal operations according to the delegation protocol and can return the delegate's completion value.

04

next

A generator's next(value) resumes execution. Its result reports a yielded or returned value and whether the generator has completed; the first supplied value has no suspended yield to receive it.

05

throw

throw raises an exception. A generator's throw(error) resumes it by throwing at its suspended point, where a surrounding catch may handle the error.

06

return

return completes the current function with a value. Calling a generator's return(value) requests completion and can execute finally blocks before it finishes.

07

suspended execution

Suspended execution preserves a generator or async function's continuation while other work proceeds. Resuming it continues from that point rather than calling the function from the beginning.

function* range(start, end) {
  try {
    for (let value = start; value < end; value += 1) {
      const command = yield value;
      if (command === "stop") return "stopped";
    }
    return "complete";
  } finally {
    console.log("iterator resources released");
  }
}

const iterator = range(1, 5);
console.assert(iterator[Symbol.iterator]() === iterator);
console.log(iterator.next());        // { value: 1, done: false }
console.log(iterator.next());        // { value: 2, done: false }
console.log(iterator.next("stop"));  // { value: "stopped", done: true }
