04 · Detailed term guide

Follow writes into internal queues, thresholds signalling producer slowdown, drain notification, batching, and finalization.

01

Writable streams

A Writable accepts chunks into an internal queue and reports completion after its sink handles them. Its write return value communicates pressure.

02

highWaterMark

highWaterMark is an internal queue threshold that triggers backpressure signals. It is not a strict total-memory limit for the process.

03

write return values

A false return from writable.write signals backpressure: stop writing until drain rather than treating false as write failure.

04

drain

After write returns false, drain signals that the buffered writes have drained and the producer may resume. It is not a durability acknowledgment or merely an arbitrary drop below highWaterMark.

05

cork

Writable corking buffers writes until matching uncork calls or end. It does not automatically uncork on the next tick; callers often schedule uncork with process.nextTick to batch writes for _writev.

06

backpressure

Backpressure makes an upstream producer slow down when downstream capacity is full, preventing queues and memory from growing with total input.

import { Writable } from "node:stream";
import { once } from "node:events";

const sink = new Writable({
  highWaterMark: 16 * 1024,
  write(chunk, encoding, callback) { setTimeout(callback, 2); }
});

for (let index = 0; index < 10_000; index += 1) {
  const canContinue = sink.write(Buffer.alloc(1024));
  if (!canContinue) await once(sink, "drain");
}
sink.end();
await once(sink, "finish");

console.log({ writableLength: sink.writableLength, destroyed: sink.destroyed });
// Ignoring false allows the JavaScript-side write queue to grow with input.
