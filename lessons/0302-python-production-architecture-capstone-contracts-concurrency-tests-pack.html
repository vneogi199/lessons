Python production architecture capstone

The capstone connects language mechanics to one operated system. Its quality is demonstrated by contracts, measurements, failure tests, build artifacts, security review, and a usable runbook.

contracts

A contract states observable inputs, outputs, guarantees, errors, and constraints that callers may rely on. It includes failure behavior, not just a function signature.

concurrency

Concurrency allows tasks to make overlapping progress. Shared state still needs an explicit ordering or ownership rule.

tests

Tests compare actual behavior with an explicit expectation under controlled conditions. A passing test proves only the cases and assumptions it exercises.

packaging

Packaging turns source and metadata into installable distribution artifacts. It is separate from importing a package and from deploying an application.

operations

Operations covers running, observing, changing, and recovering a service, with named owners and tested procedures.

from contextlib import asynccontextmanager
from dataclasses import dataclass
from typing import Protocol

@dataclass(frozen=True)
class CreateProject:
    name: str
    idempotency_key: str

class UnitOfWork(Protocol):
    async def __aenter__(self): ...
    async def __aexit__(self, exc_type, exc, tb): ...
    async def claim(self, key: str, intent: tuple[str, str]) -> dict | None: ...
    async def add_project(self, project: dict) -> dict: ...
    async def save_result(self, key: str, project: dict): ...
    async def commit(self): ...

class ProjectService:
    def __init__(self, uow_factory):
        self.uow_factory = uow_factory
    async def create(self, command: CreateProject) -> dict:
        if not isinstance(command.name, str) or not command.name.strip():
            raise ValueError("name required")
        if not isinstance(command.idempotency_key, str) or not command.idempotency_key:
            raise ValueError("idempotency key required")
        name = command.name.strip()
        async with self.uow_factory() as uow:
            prior = await uow.claim(command.idempotency_key, ("create-project-v1", name))
            if prior is not None:
                return prior
            project = await uow.add_project({"name": name})
            await uow.save_result(command.idempotency_key, project)
            await uow.commit()
            return project

# Adapter contract: factory is scoped to authenticated tenant + operation.
# claim atomically inserts identity/intent or returns the original stored result;
# changed intent raises. Receipt, project and saved result commit together.
# __aexit__ rolls back on exceptions or uncommitted exit. A typing Protocol does
# not implement this transaction. Test concurrency/rollback on the real adapter.
# Evidence: strict types, contract tests, bounded concurrency, profiles,
# wheel inspection, dependency provenance, graceful shutdown, and runbook.
