Attribute lookup, descriptors, properties, slots, __getattribute__, and __getattr__

ELI5 example

An object can expose a temperature attribute while checking assignments through a property. Reading or assigning that name can therefore call code instead of simply reading or replacing a stored field.

Properties use the descriptor mechanism. Attribute lookup decides which stored value or descriptor applies. __getattr__ is a fallback for a missing attribute; it is not the same hook as __getattribute__.

Can reading an attribute execute code?

Yes. A property getter is one example.

Attribute access can run code instead of reading stored data directly. Descriptors control access, and a data descriptor takes priority over an instance's dictionary during normal lookup. A property uses this mechanism for managed access. __getattribute__ participates in ordinary lookup, while __getattr__ handles missing attributes. Slots affect storage, but a class that includes __dict__ still permits dictionary-backed attributes.

01

Attribute lookup

Attribute lookup coordinates descriptors, instance storage, class inheritance, and fallback hooks.

02

descriptors

A descriptor is an attribute object defining __get__, __set__, or __delete__. Functions, properties, class methods, slots, and many framework fields use this attribute protocol.

03

properties

A property is a data descriptor that turns attribute access into method calls. It can preserve a clean public API while computing or validating a value.

04

slots

__slots__ declares descriptor-backed instance fields and can omit a per-instance dictionary. It may save memory but restricts dynamic attributes and complicates inheritance.

05

__getattribute__

__getattribute__ participates in ordinary instance attribute access; custom implementations must avoid accidental recursive lookup.

06

__getattr__

__getattr__ supplies fallback behavior when normal attribute lookup fails.

class Positive:
    def __set_name__(self, owner, name):
        self.name = name
    def __get__(self, instance, owner=None):
        if instance is None:
            return self
        return instance.__dict__[self.name]
    def __set__(self, instance, value):
        if type(value) is not int or value <= 0:
            raise ValueError(f"{self.name} must be a positive integer")
        instance.__dict__[self.name] = value

class Batch:
    size = Positive()  # data descriptor outranks instance lookup
    __slots__ = ("__dict__", "label")
    def __init__(self, label: str, size: int):
        self.label, self.size = label, size
    def __getattr__(self, name):
        if name == "summary":
            return f"{self.label}:{self.size}"
        raise AttributeError(name)

assert Batch("jobs", 3).summary == "jobs:3"
for bad in (0, -1, True, float("nan")):
    try:
        Batch("jobs", bad)
    except ValueError:
        pass
    else:
        raise AssertionError("invalid batch size accepted")
