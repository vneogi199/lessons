Memory, V8 heap, external memory, RSS, garbage collection, heap snapshots, and leaks

Node.js runs JavaScript outside a browser. It connects JavaScript to files, networks, processes, and operating-system services.

01

Memory

Memory holds active code and data. Measure retained objects, buffers, and peak allocation, not just average usage.

02

V8 heap

The V8 heap stores garbage-collected JavaScript objects across managed spaces. It excludes substantial Buffer, native, stack, and other process memory.

03

external memory

External memory includes allocations associated with JavaScript objects but owned outside the V8 heap, notably Buffer and native resources.

04

RSS

Resident set size estimates physical memory currently mapped into the process, including heap, native allocations, code, stacks, libraries, and allocator fragmentation.

05

garbage collection

Garbage collection reclaims memory that is no longer needed under the runtime's reachability rules. Its timing is not a dependable way to close external resources.

06

heap snapshots

A heap snapshot records objects and reference edges so retaining paths can identify which live root prevents expected collection.

07

leaks

A leak retains resources longer than their intended lifetime. Look for growing ownership paths such as listeners, caches, handles, or unfinished work under comparable load.
