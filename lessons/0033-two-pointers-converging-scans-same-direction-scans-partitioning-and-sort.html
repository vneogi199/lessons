Two pointers

Two pointers move two indexes under an invariant to inspect pairs, partitions, or ranges efficiently.

converging scans

Two pointers move inward from opposite ends while an invariant justifies discarding candidates.

same-direction scans

Two pointers advance in the same direction, often maintaining a window or separating read and write positions.

partitioning

Partitioning rearranges or separates values according to a predicate, preserving a stated relationship between the regions.

sorted invariants

A sorted invariant states which region is ordered and how that order permits pruning or efficient lookup.

Two-pointer scans save work when moving an index proves that some candidates can be ignored. For a sorted target-pair problem, a sum that is too small justifies moving the left pointer; a sum that is too large justifies moving the right. Without sorted input, those skipped pairs may contain an answer. Other scans maintain read/write regions or partitions, so state the rule for the particular problem rather than copying pointer movements.

function sortedPair(values, target) {
  let left = 0, right = values.length - 1;
  const trace = [];
  while (left < right) {
    const sum = values[left] + values[right];
    trace.push({ left, right, sum });
    if (sum === target) return { indices: [left, right], trace };
    if (sum < target) left++; else right--;
  }
  return { indices: undefined, trace };
}

const answer = sortedPair([2, 5, 8, 11, 15, 19], 19);
console.assert(JSON.stringify(answer.indices) === "[2,3]");
console.assert(answer.trace.length === 5);
// Sorted order proves every skipped pair is impossible: O(n) after sorting,
// versus checking O(n²) pairs. If input is unsorted, sort or use a hash map.

Discard impossible pairs using sorted order

Find a pair totaling 19 in [2, 5, 8, 11, 15, 19].

Outer pairs
2 + 19 = 21 → move right left
2 + 15 = 17 → move left right
5 + 15 = 20 → move right left
Remaining checks
5 + 11 = 16 → move left right
8 + 11 = 19
Return indexes [2, 3]

1. Why can a sum below 19 move the left pointer?

Answer checkpoints

For that left value, every remaining right value is no larger than the current one. None can reach the target. Sorted order supports the discard.
