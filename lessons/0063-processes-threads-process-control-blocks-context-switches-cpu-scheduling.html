01

Processes

Processes are operating-system execution units with their own resource and address-space context; they may contain multiple threads.

02

threads

Threads execute within a process and commonly share its memory, making concurrent access and lifetime coordination important.

03

process control blocks

A process control block stores kernel bookkeeping for an execution context, including scheduling and resource state.

04

context switches

A context switch saves one execution context and restores another, with direct work and possible cache-related costs.

05

CPU scheduling

CPU scheduling selects runnable work according to policy, balancing responsiveness, throughput, and fairness.

06

IPC

Inter-process communication transfers data or coordination between processes, using mechanisms such as pipes, sockets, or shared memory. Each mechanism has ownership and synchronization costs.

from collections import deque

def round_robin(bursts: dict[str, int], quantum: int) -> list[tuple[str, int]]:
    if type(quantum) is not int or quantum <= 0:
        raise ValueError("positive integer quantum required")
    if any(type(burst) is not int or burst <= 0 for burst in bursts.values()):
        raise ValueError("positive integer bursts required")
    ready, trace = deque(bursts), []
    remaining = bursts.copy()
    while ready:
        task = ready.popleft()
        ran = min(quantum, remaining[task])
        remaining[task] -= ran
        trace.append((task, ran))
        if remaining[task]:
            ready.append(task)
    return trace

trace = round_robin({"api": 5, "worker": 3}, quantum=2)
assert trace == [("api", 2), ("worker", 2), ("api", 2), ("worker", 1), ("api", 1)]
assert round_robin({}, 1) == []
for bursts, quantum in [({"a": 1}, 0), ({"a": -1}, 2), ({"a": 0}, 2)]:
    try: round_robin(bursts, quantum)
    except ValueError: pass
    else: raise AssertionError("non-progressing schedule accepted")
