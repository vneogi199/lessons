ELI5 example

A frozen dataclass blocks ordinary field assignment. It does not freeze a list held inside a field. If you need a value that cannot change, inspect its contents as well as the outer record.

Does frozen make a nested list immutable?

No. The list can still be mutable.

Dataclasses

A dataclass generates common methods from annotated fields. It reduces boilerplate but does not perform general runtime type validation.

named tuples

Named tuples are tuple subclasses whose fields also have names. They support positional access and unpacking while making records clearer; their outer structure is immutable, but referenced children may be mutable.

enums

An Enum defines a closed set of named singleton members. It communicates domain choices more clearly than scattered strings or integers.

frozen models

Frozen models restrict field assignment under their library's contract; nested mutable objects may still change.

value objects

Value objects represent meaning through their values rather than lifecycle identity, such as an amount with currency.

from dataclasses import dataclass, field
from decimal import Decimal
from enum import StrEnum

class Currency(StrEnum):
    USD = "USD"
    EUR = "EUR"

@dataclass(frozen=True, slots=True)
class Money:
    amount: Decimal
    currency: Currency
    tags: tuple[str, ...] = field(default_factory=tuple)

    def __post_init__(self):
        if not isinstance(self.amount, Decimal) or not self.amount.is_finite():
            raise ValueError("amount must be a finite Decimal")
        if not isinstance(self.currency, Currency):
            raise ValueError("currency must be a Currency member")

    def __add__(self, other: "Money") -> "Money":
        if not isinstance(other, Money):
            return NotImplemented
        if self.currency is not other.currency:
            raise ValueError("currency mismatch")
        return Money(self.amount + other.amount, self.currency)

assert Money(Decimal("2"), Currency.USD) + Money(Decimal("3"), Currency.USD) == Money(Decimal("5"), Currency.USD)
for bad in (Decimal("NaN"), Decimal("Infinity"), Decimal("-Infinity")):
    try:
        Money(bad, Currency.USD)
    except ValueError:
        pass
    else:
        raise AssertionError("non-finite money accepted")
# Arithmetic here deliberately drops tags; production needs an explicit metadata
# and rounding policy. A frozen dataclass does not validate annotations by itself.
