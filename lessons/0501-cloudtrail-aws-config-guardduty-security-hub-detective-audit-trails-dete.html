04 · Detailed term guide

Distinguish API history, resource configuration state, threat findings, aggregation, investigation, and automated remediation.

01

CloudTrail

AWS CloudTrail records supported account and API activity under configured event collection. Management-event history and selected data-event trails have different coverage and retention.

02

AWS Config

AWS Config records supported resource configurations and evaluates configured rules. It explains observed state and compliance findings rather than replacing a full API audit history.

03

GuardDuty

Amazon GuardDuty analyzes supported data sources for threat findings. Coverage, enabled protections and investigation determine what a finding means; detection does not itself prove compromise or complete containment.

04

Security Hub

AWS Security Hub brings together supported security findings and posture information. Configured integrations, coverage and response ownership determine whether aggregation improves remediation.

05

Detective

Amazon Detective provides related security activity views for investigation under its supported service coverage. Treat correlation as investigative evidence and verify current account/Region availability before designing around it.

06

audit trails

Audit trails preserve attributable activity records with configured coverage, integrity, access and retention. Missing collection cannot be repaired by assuming every request was logged.

07

detection

Detection identifies activity that matches a rule or threat hypothesis. Validate false positives, missing coverage and incident context before choosing a response.

08

response

Security response investigates, contains and recovers from a suspected incident using authorized actions. Preserve evidence, assign an owner and verify the effect of mitigation.

08 · Common mistakes

Memorizing the label

A definition is not enough. Trace AWS evidence and response from input to output.

Testing only success

The happy path can hide a weak design. Try this failure: Keep process health green while requests fail, then remove one telemetry source and reassess the conclusion.

Changing too much

Change one condition at a time. Otherwise, you will not know what caused the result.
