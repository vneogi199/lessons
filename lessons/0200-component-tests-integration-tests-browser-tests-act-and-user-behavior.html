Component tests

Component tests exercise rendered behavior and interactions with controlled collaborators rather than private implementation details.

integration tests

Integration tests exercise cooperating components across a real boundary, such as an application and database. They can expose behavior that isolated fakes omit.

browser tests

Browser tests verify behavior in an actual browser, including navigation, layout-sensitive interactions, and integration boundaries.

act

act helps tests flush React-related updates before assertions; user-facing testing helpers often coordinate it.

user behavior

User behavior is observable interaction and outcome, such as submitting a form and seeing an error, not an internal setter call.

Test the behavior a user can observe at the boundary that provides it. Hold a dependency pending to establish loading behavior, then resolve or reject it and await the displayed result. Use accessible roles and names when finding controls. act coordinates React updates, but a simulated DOM does not provide real layout, navigation or assistive technology. Use browser evidence for those claims.
