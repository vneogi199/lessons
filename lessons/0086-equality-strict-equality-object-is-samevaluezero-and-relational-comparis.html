Compare the language's equality algorithms and identify where arrays, sets, maps, includes, indexOf, and sorting use different sameness rules.

01

Equality

JavaScript has several equality relations. Choose strict equality, Object.is, or SameValueZero according to the required treatment of types, NaN, signed zero, and object identity.

02

strict equality

Strict equality compares without type conversion. It compares primitives mostly by value and objects by identity, while treating NaN as unequal to itself and both zeros as equal.

03

Object.is

Object.is implements SameValue comparison. Unlike strict equality, it treats NaN as equal to itself and positive and negative zero as different.

04

SameValueZero

SameValueZero treats NaN as equal to itself and both zeros as equal. Map, Set, and Array includes use this equality model.

05

relational comparison

Relational operators compare ordered values after specified conversions. Two strings compare lexicographically by code units; mixed operands and NaN require separate reasoning.
