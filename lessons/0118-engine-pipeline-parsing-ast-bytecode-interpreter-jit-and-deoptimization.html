Engine pipeline, parsing, AST, bytecode, interpreter, JIT, and deoptimization

JavaScript is a programming language. A JavaScript engine reads the program and performs its operations.

Senior practice for this track ↗ · The reading estimate excludes the lab and interview rehearsal.

An engine parses source and executes an internal representation. It can use observed behavior to compile specialized code for frequently used paths. Guards check the assumptions behind that code; deoptimization supplies a fallback when they no longer hold. These execution choices must preserve the language result. Use engine diagnostics to establish which path ran, since timing alone cannot identify a compiler tier.

01

Engine pipeline

A JavaScript engine parses source and executes it through implementation-specific interpreter and compiler tiers. Optimization is adaptive and must preserve ECMAScript behavior.

02

parsing

Parsing checks source syntax and constructs an internal representation. An engine's parser may defer work, but all optimizations must preserve observable language semantics.

03

AST

An abstract syntax tree represents the syntactic structure of a program. It is an implementation/tooling representation, not a trace of actual runtime calls.

04

bytecode

Bytecode is an engine-specific instruction representation used by some execution tiers. Its format is not a portable JavaScript API.

05

interpreter

An interpreter executes an internal representation without requiring every path to be optimized machine code first. Modern engines can combine interpretation and compilation tiers.

06

JIT

Just-in-time compilation generates machine code during execution, often using observed behavior to specialize hot paths. Its benefits and warmup costs depend on the workload and engine.

07

deoptimization

Deoptimization moves execution out of specialized code when its assumptions no longer hold. Correct engines preserve the same language result despite changing execution strategy.

import { performance } from "node:perf_hooks";

function total(points) {
  let sum = 0;
  for (const point of points) sum += point.x + point.y;
  return sum;
}

const stable = Array.from({ length: 100_000 }, (_, index) => ({ x: index, y: 1 }));
console.assert(total(stable) === 5_000_050_000); // Verify work before timing it.
for (let warmup = 0; warmup < 20; warmup += 1) total(stable);

const samples = [];
for (let run = 0; run < 30; run += 1) {
  const started = performance.now();
  total(stable);
  samples.push(performance.now() - started);
}
samples.sort((a, b) => a - b);
console.table({
  medianMs: samples[Math.floor(samples.length * 0.5)],
  p95Ms: samples[Math.floor(samples.length * 0.95)]
});

// V8 experiment flags: node --print-bytecode experiment.mjs
// Treat shapes, inline caches, and deoptimization as measured implementation
// explanations—not portable correctness rules.
