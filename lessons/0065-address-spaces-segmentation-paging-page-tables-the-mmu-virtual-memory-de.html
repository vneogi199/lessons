Address spaces

An address space is the range and mapping of addresses visible to an execution context.

segmentation

Segmentation maps logical memory regions with region-specific bounds or permissions; it differs from fixed-size paging.

paging

Paging maps fixed-size virtual pages to physical frames, allowing flexible placement and protection.

page tables

Page tables describe virtual-to-physical mappings and access permissions used during address translation.

the MMU

The memory management unit performs hardware-supported address translation and permission checking.

virtual memory

Virtual memory gives processes an address abstraction separate from physical placement, supporting isolation and demand-based allocation.

demand paging

Demand paging brings a required page into memory when access faults rather than loading everything eagerly.

replacement

Page replacement chooses which resident page to evict when memory is needed, trading future faults against current pressure.

Virtual memory separates the addresses a process uses from their physical placement. Paging splits an address into a page number and offset, then uses a mapping to select a physical frame. The MMU also checks access permissions. A missing or protected mapping can cause a fault that needs different handling depending on its cause. Demand-zero, copy-on-write and file-backed faults do not all require swap. Replacement chooses what to evict under pressure; the toy LRU model does not establish a real operating system's policy.

from collections import OrderedDict

def translate(virtual_address: int, page_size: int, page_table: dict[int, int]) -> int:
    if type(virtual_address) is not int or virtual_address < 0 or type(page_size) is not int or page_size <= 0:
        raise ValueError("nonnegative address and positive page size required")
    virtual_page, offset = divmod(virtual_address, page_size)
    if virtual_page not in page_table:
        raise LookupError("page fault")
    return page_table[virtual_page] * page_size + offset

assert translate(0x1234, 4096, {1: 9}) == 0x9234

def lru_faults(pages: list[int], capacity: int) -> int:
    if type(capacity) is not int or capacity < 0:
        raise ValueError("nonnegative capacity required")
    if capacity == 0:
        return len(pages)
    resident, faults = OrderedDict(), 0
    for page in pages:
        if page not in resident:
            faults += 1
            if len(resident) == capacity: resident.popitem(last=False)
        else: resident.pop(page)
        resident[page] = True
    return faults

assert lru_faults([1, 2, 1, 3, 1], 2) == 3
assert lru_faults([1, 1], 0) == 2
assert lru_faults([], 0) == 0
