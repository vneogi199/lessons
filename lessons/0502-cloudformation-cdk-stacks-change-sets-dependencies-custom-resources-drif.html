CloudFormation

CloudFormation turns a template into ordered AWS API changes and records stack state. A failed update may roll back, while replacements can destroy and recreate resources.

CDK

AWS CDK expresses infrastructure in supported programming languages and synthesizes CloudFormation templates. Generated resources still need review for permissions, replacement and deployment behavior.

stacks

A CloudFormation stack groups resources managed through one template and lifecycle. Cross-stack references and shared data can constrain independent updates or deletion.

change sets

CloudFormation change sets preview supported resource changes before execution. They can expose replacements but do not guarantee successful deployment or safe application data migration.

dependencies

Dependencies are components required for behavior or builds. Their versions, failure modes, and trust become part of the system's obligations.

custom resources

CloudFormation custom resources delegate lifecycle actions to a supplied provider. That provider must report completion and handle retries, updates, deletion and stable physical identity correctly.

drift

Configuration drift is a difference between the intended configuration and the observed system. Detect the difference and decide whether to reconcile or deliberately change the declared intent.

infrastructure testing

Infrastructure testing checks template shape, policy intent, planned changes and actual deployed behavior at appropriate boundaries. Static validation alone cannot verify live routing or restore capability.
