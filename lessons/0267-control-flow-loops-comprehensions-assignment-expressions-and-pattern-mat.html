Control flow, loops, comprehensions, assignment expressions, and pattern matching

ELI5 example

Take quantities 2, 0 and 3. To keep positive quantities, inspect each one: keep 2, skip 0, keep 3. The result is 2 and 3.

A for loop expresses the repeated inspection. An if chooses whether to keep the current item. A comprehension can express the same small transformation in one expression; a complicated decision may be easier to read as a loop.

Does filtering change the original list automatically?

No. Building a filtered list creates a result; changing the original requires a separate operation.

A condition selects a branch, and a loop repeats work over values or while a condition holds. Comprehensions build collections from that repeated work. An assignment expression can name a value while testing it. Pattern matching selects a branch from a value's structure, but matching alone does not establish every input rule. Control flow

Control flow chooses which statements execute through conditions, loops, exceptions, and function calls.

loops

Loops repeat work by iteration or a condition; break and continue alter progress, while loop else depends on normal completion.

comprehensions

A comprehension declaratively builds a collection from iteration, filtering, and transformation. In Python 3 it has its own implicit scope for loop variables.

assignment expressions

The := operator binds a value inside an expression; use it only when the resulting control flow stays clear.

pattern matching

Structural pattern matching checks the shape and contents of a value and may bind names. Guards add conditions after a structural pattern succeeds.

from dataclasses import dataclass

@dataclass(frozen=True)
class Create:
    name: str

def execute(command):
    match command:
        case {"type": "create", "name": str(name)} if name.strip():
            return Create(name.strip())
        case ["sum", *raw_values]:
            return sum(int(value) for value in raw_values)
        case {"type": unknown}:
            raise ValueError(f"unknown command: {unknown}")
        case _:
            raise TypeError("unsupported command shape")

assert execute({"type": "create", "name": "  demo "}) == Create("demo")
assert execute(["sum", "2", "3"]) == 5
