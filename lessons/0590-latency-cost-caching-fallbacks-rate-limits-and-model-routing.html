Latency

Latency is the elapsed time between starting a request and receiving a specified result.

cost

Cost is the measurable resource or financial expense of model input, output, storage, and supporting services.

caching

Caching stores a reusable result so the application can avoid repeated model work.

fallbacks

A fallback is a defined alternative path used when the preferred model or operation is unavailable or unsuitable.

rate limits

Rate limits restrict request frequency, token volume, or concurrency during a time interval.

model routing

Model routing selects a model or provider according to task needs, quality, latency, availability, and cost.
