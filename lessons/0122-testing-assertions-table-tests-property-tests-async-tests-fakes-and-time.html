A useful test states observable behavior and fails when that behavior breaks. Tables cover chosen cases; property tests generate inputs to check a general rule. Await asynchronous assertions so the test cannot finish before the failure. Fakes make dependencies controllable but need agreement with the relevant real behavior. Testing

JavaScript testing should verify observable contracts across normal, boundary, failure, async, and cleanup paths while avoiding implementation-coupled mocks.

assertions

An assertion checks that a stated condition holds during a test or execution. Know whether your assertion mechanism throws, only logs, or can be disabled.

table tests

Table tests run one behavior against an explicit list of input and expected-result cases. Include normal, boundary, and failure inputs.

property tests

Property tests run many generated inputs against a general invariant. A failing case should be reduced to a small reproducible counterexample.

async tests

Async tests wait for the operation under test and assert its result, error, and cleanup. An unreturned or unawaited promise can let a test finish before failure is observed.

fakes

A fake is a simplified working substitute for a dependency, such as an in-memory store. Verify that its relevant behavior agrees with the real dependency.

timers

Timers schedule callbacks after a delay threshold under host rules. The delay is not an exact execution time; a busy event loop can run the callback later.

import assert from "node:assert/strict";
import test from "node:test";

function normalize(value) { return value.trim().normalize("NFC").toLowerCase(); }

for (const [input, expected] of [[" Ada ", "ada"], ["É", "é"]]) {
  test("normalize " + JSON.stringify(input), () => {
    assert.equal(normalize(input), expected);
    assert.equal(normalize(normalize(input)), expected); // idempotence property
  });
}

test("abort is observable", async () => {
  const controller = new AbortController();
  const reason = new Error("test cancellation");
  controller.abort(reason);
  await assert.rejects(
    () => fetch("https://example.invalid", { signal: controller.signal }),
    error => error === reason
  );
});
