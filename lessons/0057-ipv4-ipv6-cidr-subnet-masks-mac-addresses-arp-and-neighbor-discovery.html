IPv4, IPv6, CIDR, subnet masks, MAC addresses, ARP, and neighbor discovery

Networking moves messages between programs and machines. An operating system manages processes, memory, files, devices, and protected access to hardware.

Senior practice for this track ↗ · The reading estimate excludes the lab and interview rehearsal.

An IP address identifies a network destination; a MAC address identifies an interface for local-link delivery. A CIDR prefix separates the network bits from the remaining address bits. For a destination outside the local network, the next-hop link address belongs to the gateway, not the remote host. IPv4 uses ARP to find a neighbor's link address. IPv6 uses Neighbor Discovery. Keep the prefix, next hop and neighbor entry separate when diagnosing a failed connection.

IPv4

IPv4 uses 32-bit addresses and packet delivery without an end-to-end reliability guarantee.

IPv6

IPv6 uses 128-bit addresses and different network-control mechanisms, including neighbor discovery rather than ARP.

CIDR

CIDR expresses a network prefix as an address and prefix length, such as /24 for 24 fixed leading bits.

subnet masks

A subnet mask identifies the network-prefix bits of an IPv4 address.

MAC addresses

MAC addresses identify link-layer interfaces within relevant local-link communication; they are not globally routed IP destinations.

ARP

ARP discovers an IPv4 neighbor's link-layer address on a local network.

neighbor discovery

IPv6 neighbor discovery uses ICMPv6 for functions including neighbor address resolution and router discovery.

from ipaddress import ip_address, ip_network

subnet = ip_network("192.0.2.0/27")
host = ip_address("192.0.2.18")
remote = ip_address("198.51.100.8")
assert host in subnet and remote not in subnet
assert str(subnet.netmask) == "255.255.255.224"

neighbor_cache: dict[str, str] = {}
def learn_neighbor(ip: str, mac: str) -> None:
    if ip_address(ip) not in subnet:
        raise ValueError("ARP learns only an on-link next hop")
    neighbor_cache[ip] = mac

learn_neighbor("192.0.2.1", "02:00:00:00:00:01")
next_hop = str(remote) if remote in subnet else "192.0.2.1"
assert neighbor_cache[next_hop].endswith(":01")
# IPv4 uses ARP; IPv6 uses Neighbor Discovery. Both resolve an on-link next hop.

Check your reasoning after answering

A /27 has 32 IPv4 addresses; this sample checks prefix membership, not whether every address is assignable to a host. For an off-link destination, resolve the gateway's link address rather than the remote host's. The one-subnet cache is a simplified model: real on-link routes, proxy ARP and multiple interfaces need additional policy. IPv6 uses Neighbor Discovery, not ARP. Compare network prefix, next hop and neighbor entry separately when diagnosing reachability.
