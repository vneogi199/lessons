04 · Detailed term guide

How they connect: Compare forwarding by IP address and transport port with terminating and routing HTTP requests by host, path, header, method, or content while tracing connection ownership, pooling, source identity, encryption, retries, and target health.

01

Layer 4

What it means: Layer-4 balancing operates primarily on transport connections rather than application request semantics.

02

Layer 7 load balancing

What it means: Layer-7 balancing uses application information such as HTTP routes, with protocol parsing and policy costs.

03

transport flows

What it means: A transport flow is a connection identified by network and transport addresses whose packets must reach a consistent backend while that connection is active.

04

HTTP routing

What it means: HTTP routing selects a backend from application data such as host, path, method, header, or cookie after TLS is terminated where inspection is required.

05

algorithms

What it means: A load-balancing algorithm selects an eligible target using rules such as round robin, least outstanding work, hashing, or weighted capacity.

06

health checks

What it means: A health check tests whether a target should receive new traffic. It must represent readiness without causing synchronized overload or hiding dependency failure.

07

affinity

What it means: Affinity attempts to keep related connections or requests on the same target, which can help local session state but creates uneven load and failover limits.

08

TLS

What it means: TLS placement decides where traffic is decrypted, which identity is authenticated, which routing data becomes visible, and whether encryption continues to the backend.

09

proxies

What it means: A proxy handles traffic on behalf of another endpoint. Its routing, timeout, buffering, trust, and header behavior can change the end-to-end result.

10

failure modes

What it means: Load-balancer failure modes include unhealthy targets, stale health, overload, connection resets, retry amplification, uneven hashing, proxy timeout mismatch, and loss of a balancing tier.

type Target = { id: string; healthy: boolean; outstanding: number; zone: string };

function leastOutstanding(targets: readonly Target[], localZone: string): Target {
  const healthy = targets.filter(target => target.healthy);
  if (!healthy.length) throw new Error("no healthy targets");
  const local = healthy.filter(target => target.zone === localZone);
  return (local.length ? local : healthy).reduce((best, target) =>
    target.outstanding < best.outstanding ? target : best);
}

function layer7Route(request: Request): "api" | "static" {
  const url = new URL(request.url);
  if (url.hostname === "api.example.com" || url.pathname.startsWith("/api/")) return "api";
  return "static";
}

const targets = [
  { id: "a", healthy: true, outstanding: 8, zone: "az-1" },
  { id: "b", healthy: true, outstanding: 2, zone: "az-1" },
  { id: "c", healthy: false, outstanding: 0, zone: "az-2" },
];
console.assert(leastOutstanding(targets, "az-1").id === "b");
