Generators, yield, generator frames, send, throw, close, and delegation

ELI5 example

A generator can hand you one item, pause, then continue when you ask for another. Its paused work keeps the local state needed to continue.

yield marks that pause. This lets you avoid building all results at once, but the suspended generator can still retain objects and resources. Resource cleanup needs a deliberate owner.

Does yielding discard all local variables?

No. The generator retains the state needed to resume.

Calling a generator function creates a generator without running its body. Advancing it runs the body until yield pauses execution and returns a value. The suspended frame retains local state. send and throw resume it with a value or exception, while close requests cleanup. yield from delegates this behavior to another iterator. If the generator owns a file, give it an explicit lifetime; leaving a loop does not automatically close an externally retained generator.

01

Generators

A generator is an iterator backed by a suspended Python frame. Each next resumes execution until yield, return, or an exception.

02

yield

yield emits a value and suspends the generator while preserving its local state and instruction position. Calling the generator function creates the generator without running its body.

03

generator frames

A frame is the runtime record for one executing code block. It connects bytecode, local and global namespaces, the instruction position, and the caller frame.

04

send

Generator send resumes execution while supplying the value of the suspended yield expression.

05

throw

Generator throw raises an exception at the suspension point, allowing the generator's handlers or cleanup to respond.

06

close

Generator close requests termination and cleanup through GeneratorExit; it is not a normal request for another item.

07

delegation

yield from delegates iteration and parts of the generator protocol to another iterable or generator.

from collections.abc import Generator, Iterable, Iterator

def managed_lines(path: str) -> Generator[str, None, int]:
    count = 0
    handle = open(path, encoding="utf-8")
    try:
        for line in handle:
            count += 1
            yield line.rstrip("\n")
    finally:
        handle.close()
    return count

def flatten(groups: Iterable[Iterable[str]]) -> Iterator[str]:
    for group in groups:
        yield from group

generator = flatten([["a", "b"], ["c"]])
assert next(generator) == "a"
generator.close()  # injects GeneratorExit at suspension
