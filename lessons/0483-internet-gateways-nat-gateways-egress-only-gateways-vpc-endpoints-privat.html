Internet gateways

An internet gateway connects a VPC to the internet when addressing and routing permit. IPv4 public address mapping and IPv6 routing differ; attaching the gateway alone does not expose every resource.

NAT gateways

A NAT gateway translates supported outbound connections and their return traffic. Public and private NAT modes serve different paths; route placement, address family, availability and metered traffic affect the design.

egress-only gateways

An egress-only internet gateway permits outbound IPv6 connections and return traffic while preventing unsolicited inbound internet connections. It is not IPv4 NAT or an application authorization control.

VPC endpoints

VPC endpoints provide supported private service paths. Gateway endpoints use routes, while interface endpoints use private interfaces and service DNS; endpoint policy complements service authorization.

PrivateLink

AWS PrivateLink exposes supported services through private endpoint connections without general network peering. Consumers reach the selected service; they do not gain arbitrary transitive access to its VPC.

peering

VPC peering routes permitted traffic directly between two VPCs with compatible address space. It is nontransitive: peering A to B and B to C does not create A-to-C connectivity.

Transit Gateway

A Transit Gateway connects networks through a routing hub with attachments and route tables. Association and propagation determine segmentation; connectivity and return routes must be designed explicitly.
