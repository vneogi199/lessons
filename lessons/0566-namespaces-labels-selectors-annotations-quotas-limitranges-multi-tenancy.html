Kubernetes stores desired state in API objects. Controllers work continuously to make actual state match desired state.

Kubernetes is a control room: you declare desired state through an API, controllers compare it with reality, and node agents keep reconciling until status matches or evidence explains why not.

01

Namespaces

Namespaces separate names or views of resources within a scope. They are not automatically complete security or resource-isolation boundaries.

02

labels

Labels are structured identifying attributes used for selection and grouping.

03

selectors

Selectors match labels to choose resources or endpoints; accidental label matches can route traffic to the wrong Pods.

04

annotations

Annotations hold nonidentifying metadata for tools or operators rather than ordinary label selection.

05

quotas

ResourceQuotas limit aggregate resource use or counts within a namespace.

06

LimitRanges

LimitRanges constrain or default supported resource requests and limits within a namespace.

07

multi-tenancy

Multi-tenancy shares infrastructure among tenants while requiring explicit identity, network, resource, and data isolation.

08

isolation boundaries

Isolation boundaries define which failures, privileges, and resources are separated; a namespace alone is not a complete hostile-tenant boundary.
